CharGPT'den öğrendiğim kadarıyla, &metin ifadesinin farkı da var:
Tüm dizinin adresi deyip duruyordu,
tüm dizinin adresi ne demek dediğimde ise,
örneğin &metin + 1 yapıldığında tüm diziyi atlar dedi.
pointer aritmetiği aklıma gelmemişti, ve gerçekten de tüm dizinin adresine bir eklenirse bir sonraki diziye geçilir fikri çok makul (muhtemelen doğru bilgi zaten).
Öyleyse &metin ifadesinin türü şudur int(*)[] şunun yerine -> int *
"peki neden &metin ile &metin[0] aynı adresi tutar?" dediğimde ise şundan bahsetti, dizi ile dizinin ilk elemanının adresleri aynıdır.

void print_num_of_words_on_str(char * p)
{
    int word_cnt = 0;
    int is_space = 1;
    for (; *p != '\0';) {
        if (!isspace((unsigned char)*p) && is_space) {
            ++word_cnt;
            is_space = 0;
        }
        else if (isspace((unsigned char)*p)) {
            is_space = 1;
        }
        ++p;
    }
    printf("kelime sayisi = %d\n", word_cnt);
}
